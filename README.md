PINECREST — a 2D precision platformer. You are Pip, a small climber with a
red scarf, ascending Pinecrest Mountain at dawn to light the summit beacon.
Three hand-built levels: run, jump, double-jump, wall-jump and air-dash up
the mountain; stomp thorn-walkers, dodge spore-bats and spikes; collect
sun-shards; rest at checkpoints; reach the beacon before your three hearts
run out. No libraries, no network, no assets — every sprite is drawn in
code and every sound is synthesized with WebAudio.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser.

## Controls

| Input | Action |
| --- | --- |
| ← → or A / D | Run |
| Space, W or ↑ | Jump (press again in the air for a double jump) |
| Shift or X | Air dash |
| P or Esc | Pause |
| R | Restart the level |
| M | Mute |

Mouse clicks work on every menu button.
